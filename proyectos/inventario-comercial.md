# Inventario comercial

Un plan comercial donde cada cifra se contó en la fuente. Lo que no se pudo confirmar no aparece.

## Qué resuelve

Un plan hecho con cifras de memoria se discute; uno hecho con cifras contadas se ejecuta. El inventario parte de una pregunta: antes de buscar escuelas nuevas, ¿qué hay ya empezado y sin terminar?

## Cómo funciona

- **Una acción, un responsable.** Cada punto dice qué hacer y quién lo hace.
- **«Cómo lo confirmamos».** Debajo de cada acción va de dónde salió el dato y cómo se contó.
- **Tres horizontes.** Lo de esta semana, lo que va antes del siguiente evento y la tabla de datos y fuentes.
- **Fuente y fecha.** Cada cifra lleva el sistema del que salió y el día en que se leyó.

## Cómo está armado

Una sola página. Los datos se leen directo de cada sistema —CRM, propuestas, motor, diagnósticos, reuniones grabadas— y se cuentan ahí, no en una hoja intermedia.

## Decisiones

- Si una cifra no se pudo confirmar, se dice que no se sabe. No se estima.
- Primero lo que no cuesta: contestar a quien espera respuesta y mover lo que está detenido.
- Lo que se leyó en una muestra se reporta como muestra, no como el total.
